# ポケポケ構築理論ノート

カードゲーム一般の「強さの原理」をポケポケのルールに翻訳し、対戦シミュレーション
(sim.js / 各実験 数千〜数万試合) で検証して、「おまかせ構築」のロジックに反映した記録。

## 1. カードゲーム一般の原理 → ポケポケへの翻訳

| 一般原理 | ポケポケでの意味 |
|---|---|
| **テンポ** (資源を毎ターン無駄なく使う) | エネルギーは毎番1個。ワザコストが重い=殴れない番が増える |
| **確定数** (相手を何発で倒すか) | 3ポイント先取なので「140のexを一撃で取れるか」が試合を割る |
| **リソース交換** (取られた以上に取る) | ex=2pt、メガ=3pt。倒される価値と与える打点の収支 |
| **一貫性** (毎試合同じ動きができる) | たね確保・トレーナー枚数・単色エネルギー・進化の重さ |
| **役割分担** (先鋒/エース/壁) | 1エネで殴る先鋒 → 2-3エネのエースに繋ぐカーブ |
| **カードアドバンテージ** | 山札20枚と手札上限の世界では効きが弱い (ドロー系の価値は控えめ) |

## 2. 実験結果

対照実験プロトコル: テストコア8種で構築 → 旧既定重みで組んだメタ4デッキ
(ギャラドスex/ダークライex/メガルカリオex/ミュウツーex) と各300戦、平均勝率で比較。

### E1: トレーナー枠は何枚が最適か → **8枚 (現行維持)**
| 枠 | 4 | 6 | **8** | 10 | 12 |
|---|---|---|---|---|---|
| 勝率 | 42.8% | 44.0% | **45.0%** | 44.6% | 41.4% |

トレーナーは一貫性を買うが自分では殴らない。20枚デッキではポケモン12+トレーナー8が均衡点。

### E2: 「exは2pt献上するから非exが得」説 → **棄却**
exボーナス -40 → 37.8% / 0 → 39.3% / +30〜50 → 45.0%。
3ポイントレースではexのスタッツ(HP/打点)がポイント負債を明確に上回る。
(※メガの+3ptは別途検証済み: メガ化はほぼ等価交換 → simulation-notes.md)

### E3: 打点の価値は「素点」か「確定数」か → **確定数 (今回の最大の発見)**
線形採点(素点そのまま) 45.0% に対し、メタHP帯 (50/80/120/150/190) を跨いだ打点だけを
加点する**確定数採点で49.7%** (+4.7pt)。120→130の10点に価値はほぼ無く、130→140
(ex一撃ライン) の10点が試合を決める。hpWも0.3→0.45へ再調整。

### E4: 1エネ先鋒の強制投入 → **勝率不変 (不採用)**
初攻撃ターンは2.91→2.77と速くなるが勝率45.0%のまま。確定数採点が実質的に
軽量アタッカーを自然に拾うため、強制ルールは不要。

### E5: 新旧エンジン直接対決 (同コアで構築して1000戦×10コア)
- **直接対決: 新54.3% / 対メタ: 45.1% → 48.9% (+3.8pt)**
- 大幅改善: リザードンex 78.3%、カビゴンex 65.8%、ピカチュウex 62.2%
- 互角: 6コア / 退化: ディアルガex 37.6% (しきい値がパートナー選択を変えた副作用。既知の課題)

## 3. 採用した理論 (アプリの「おまかせ構築」に実装済み)

1. **確定数採点**: 打点はメタHP帯 [[50,20],[80,24],[120,24],[150,20],[190,16]] を跨いだ分だけ加点
2. **コスト効率最優先** (costP=35): 重いワザの大打点より軽いワザの中打点
3. **単色エネルギー優先**: 2色は事故率で明確に損 (52.5% vs 14.3%)
4. **ex肯定**: 2pt負債を恐れない
5. **トレーナー8枠 / 特性の一律加点なし / 先鋒強制なし**

## 4. 第2次実験 (①退化の原因潰し / ②妨害・補助トレーナーの実装)

### 前提の検証
- 全実験デッキが「20枚ちょうど・同名2枚以下」で構築・シミュレートされていることを
  12コアで機械検証済み (初手5枚たね保証・毎ターン1ドローの正規ルールで対戦)
- 実環境情報 (GameWith等 2026-07): Tier1 = メガルカリオex / メガジュカインex /
  ミライドンex / ゾロアークex。**シミュが独立にメガルカリオexを最強格と判定していたのと符合**。
  以後のガントレットはこの実Tier1の4デッキに変更

### ① ディアルガex退化の原因と修正
原因は2つ発見:
1. **構築エンジンがメガ=3pt献上を知らなかった** → 相方にメガクチートexを選んでいた。
   megaP(メガペナルティ)を導入。ただし強すぎると平均を落とす(メガ相方は平均的には正当)ため10に
2. **エネ加速シナジーの欠如**: ディアルガのメタルターボ(ベンチに鋼エネ2加速)があるなら
   重い相方も回るのに、一律のコストペナルティで軽い相方だけ選んでいた
   → コアが加速(ワザ/特性)を持つ場合はコストペナルティを半減する「加速シナジー」を実装

結果: ディアルガ新vs旧 37.6% → **59.7%** (完治+改善)、全体も改善。

### ② 妨害・補助トレーナーのシミュ実装
ナツメ(育った相手をベンチへ)・サカキ(とどめの+10)・レッドカード・おおきなマント(+20HP)・
スピーダー/リーフ(入れ替え)を実装。この結果**トレーナー最適枠が8→6にシフト**
(55.0% vs 52.1%): 定番7枚目以降の価値よりアタッカー1ラインが勝る。

### 最終形の成績 (旧線形エンジンとの比較)
- **直接対決(同コア10種×1000戦): 新側58.9%**
- 対実Tier1: 39.2% → **44.8% (+5.6pt)**
- 採用重み: 確定数採点 + hpW0.45 / costP35(加速持ちコアは半減) / exB30 / megaP10 / トレーナー6枠

## 5. エネルギー・タイプの公理 (ルール条文 → 理論的帰結 → 実装)

「エネルギーの色を加味しているか」の監査。ポケポケの公式ルール条文から
機械的に導かれる帰結と、エンジンでの実装状況の対応表。

| ルール条文 | 理論的帰結 | 実装 |
|---|---|---|
| ワザは指定色のエネルギーがついていないと使えない (無色コストは任意色で可) | 相方候補は「選んだ色で実際に撃てるワザ」だけで評価すべき | ✅ usableScore: 色が合わないワザは評価から除外 |
| エネルギーゾーンは毎番ランダムに1色生成 (2色登録なら各50%) | 2色は「欲しい色が来ない番」が構造的に発生 → 単色が原則 | ✅ 単色優先 (実験: 単色52.5% vs 2色14.3%)。コアが2色を要求する時だけ2色目 |
| 同上 (2色登録時の各色50%) | やむを得ず2色にする場合、相方は指定色コストが薄い(=無色主体の)ポケモンほど事故に強い | ✅ 今回実装 (下の第4次実験。2色コアの勝率14.0%→40.2%) |
| ワザ・特性の効果文が特定色を参照する (「{L}エネルギーの数×20」等) | コスト欄が無色でも、参照色がそのデッキの真の色 | ✅ 効果文の{X}トークンを色決定に算入 (ミライドンexが雷と判定されるのはこれ) |
| トレーナーカードにもエネルギーをつける効果がある (カスミ/カキ/デンジ等) | 対象ポケモンや色が合うデッキではエネ加速トレーナーが追加のテンポ源 | ✅ 第5次実験で実装 (対象がデッキにいるときだけ投入。ゾーン直出し優先) |
| **弱点タイプのワザを受けると+20ダメージ** | ①メタの弱点色で殴れば確定数が1段ズレる ②メタの主流攻撃色を弱点に持つアタッカーは先に確定数を取られる | ✅ 今回実装 (下の第3次実験) |
| にげるコスト分エネルギーを捨てる | 重いにげコストは色事故と同じくテンポ損 | ✅ シミュレータに実装 (にげコストを払えないと前に居座る)。構築側の減点は検証の結果**不採用** (第4次実験) |
| 抵抗力 | — | ポケポケには存在しない (考慮不要) |

### 第3次実験: タイプ相性項の検証
実Tier1 (メガルカリオex/メガジュカインex/ミライドンex/ゾロアークex) の構築から
メタの分布を導出: 攻撃色 = 草29.6% / 闘22.2% / 悪22.2% / 無18.5% / 雷7.4%、
弱点色 = 闘37% / 炎22.2% / 草18.5% / 超14.8% / 雷7.4%。

- **攻撃項** (自タイプがメタの弱点を突く確率で `dmgScore(dmg)` と `dmgScore(dmg+20)` を混合):
  単独では構築が変わらず勝率も不変。+20の期待値だけでは確定数の壁を越えないため
- **防御項** (自分の弱点色がメタの攻撃色と重なるシェア × typeDefP を減点):
  typeDefP=40 が最良。ケンタロスex (闘弱点=メタの22%に急所を晒す) が定番相方から外れる
- **攻防セット**で相互作用が発生: 構築が変わった7コア中、リザードンex 50.2→**57.6%**、
  ダークライex 33.2→36.1%、退化はギャラドスex 37.8→34.4% のみ。平均は明確にプラス
- 採用: `typeDefP=40` + メタ分布を既定重みに格納 (環境が変わったら `lab.js theory10` で再導出)

### 第3次実験後の最終成績
- 旧線形エンジンとの直接対決 (同コア10種×1000戦): **新側57.6%**
- 対実Tier1: 旧45.0% → **新51.7% (+6.7pt)**

### 第4次実験: 2色デッキの色濃度と、にげるコスト

**① 2色デッキの指定色コスト減点 (dualTypedP) → 採用 (10)**

2色登録時は欲しい色が毎番50%でしか来ない。この条文から「2色デッキの相方は
指定色コストが薄いほど事故に強い」を導き、2色時のみ指定色1個につき減点する項を追加。
2色コア (タケルライコ / カイリューex / カイリュー、いずれも水+雷ドラゴン) で検証:

| dualTypedP | 0 | **10** | 20 | 40 |
|---|---|---|---|---|
| 対実Tier平均 | 14.0% | **40.2%** | 40.2% | 39.7% |

**+26pt**。相方が「水×2要求のメガラグラージex」から「無色コストで撃てる
ケンタロスex/ワタッコex (どちらの色が来ても動く)」に変わったのが原因。
実際の2色構築のセオリー通りの挙動。単色デッキには一切影響しない。

**② にげるコスト**

まずルール自体をシミュレータに実装: にげるにはコスト分のエネルギーをトラッシュ、
払えなければ前に居座る (これが本当のテンポ損)。その上で構築側の減点 retreatP を探索:

| retreatP | **0** | 5 | 10 | 15 | 25 |
|---|---|---|---|---|---|
| 対実Tier平均 | **51.9%** | 47.3% | 45.7% | 45.8% | 45.5% |

**不採用 (0)**。高いにげコストは高HP・大打点と強く相関するため、減点すると
優秀なアタッカーごと弾いてしまう。にげるコストの本当の代償は「詰み場面で動けない」
ことで、それはシミュレータが再現するので診断には自然に反映される。

### 第4次実験後の最終成績
- 旧線形エンジンとの直接対決: **新側57.6%** / 対実Tier1: 旧45.7% → **新52.0%**
- 2色コアの構築が実戦水準に (14.0% → 40.2%)

### 第5次実験: トレーナーによるエネ加速 (カードテキスト起点)

従来のデータソース (hugoburguete / chase-manning) にはトレーナーの効果文が無く、
カスミ以外のエネ加速トレーナーは見えていなかった。TCGdexの元データリポジトリを
第3ソースとして取り込み、**B2aまでの全トレーナー196枚の効果文**をデータ化
(アプリの詳細表示にも和訳つきで追加)。テキストからエネ加速系を洗い出した:

| カード | 効果 (要約) | 種類 |
|---|---|---|
| カスミ (A1) | 水ポケモンにコイン加速 | ゾーン直出し |
| タケシ (A1) | ゴローニャ/イワークに闘1個 | ゾーン直出し・指名 |
| デンジ (A2) | エレキブル/レントラーに**トラッシュから**雷2個 | トラッシュ参照・指名 |
| カキ (A3) | アローラガラガラ/バクガメスに炎2個、番が終わる | ゾーン直出し・指名 |
| ほのおのパッチ (B1) | バトル場の炎ポケモンに**トラッシュから**炎1個 | トラッシュ参照 |
| メリッサ (B1) | フワライド/ムウマージに超1個ずつ | ゾーン直出し・指名 |
| エレキジェネレーター (B2a) | コインオモテでベンチの雷ポケモンに雷1個 | ゾーン直出し・コイン |

全てシミュレータに実装 (にげる/ワザで捨てたエネルギーのトラッシュ追跡も追加) し、
構築エンジンには「対象ポケモンがデッキにいるときだけ投入」の条件付き定番として組み込み。
投入優先度の実験:

- **カキをアメより優先 → バクガメスデッキ 56.9%→63.8% (+6.9pt)。採用**
- デンジを優先 → レントラー -1.7pt / エレキブル -3.2pt。**アメ後置のまま**
- エレキジェネレーター/ほのおのパッチ優先 → ±1pt内 (中立)。アメ後置のまま

**導かれた公理: エネルギーゾーンから直接出す加速は純増で強いが、トラッシュ参照の
加速は「先にエネルギーがトラッシュに落ちている」前提が20枚・3ポイント先取の短期戦では
揃いにくく、条件が噛み合うデッキ以外では枠の無駄になる。**

### 第6次実験: グッズ/どうぐ/スタジアム

カード区分 (グッズ/サポート/どうぐ/スタジアム) をデータ化し、**「サポートは1ターン
1枚」の公式ルール**をシミュレータに実装。どうぐ7種 (反撃のゴツゴツメット・どくバリ、
HPのマント2種、回復のたべのこし・オボンのみ・ラムのみ) とスタジアム4種
(トレーニングエリア・はじまりの平原・ふしぎな広場・テーブルシティ) も実装した。

構築エンジンでの採用実験 (8コア×4相手×400戦):
- ゴツゴツメット追加 51.6→52.1% / オボンのみ追加 51.6→52.1% / 両方 51.2%
- はじまりの平原 (たねのみデッキ限定) は不変 — **スタジアムは相手にも効く対称カード**
  なので、自分だけが得する盤面条件が必要 (トレーニングエリアも同様)
- 結論: どうぐ2種を定番の後段に採用 (効果は誤差の範囲内だが悪化しない)。
  スタジアムは定番化せず、ユーザーが意図を持って入れるカードとする

### 第7次実験: ポケモンのどうぐシナジー (どうぐの数で打点が伸びるコア)

カード画像から残りの未収録データを転記した結果、B3bに「場のどうぐの数だけ打点が
伸びる」アーキタイプが揃った (デデンネex「デデ・サーキット」= どうぐ1個につき40 /
エモンガ「まきつきサンダー」= 30 / ヒスイドレディア「ドレスアップ」= 装備で+20)。

- シミュレータ: 「どうぐの数×N」「装備で+N」の打点スケールを実装
  (デデ・サーキットは基礎0で、盤面全体のどうぐ数×40)
- 構築エンジン: コアがどうぐシナジーを持つとき、盤面全体に載る「どうぐ」を最優先で
  積み、トレーナー枠を10に広げる (盤面は最大4匹なので おおきなマント+オボンのみ の
  2種4枚で最大4個のどうぐを載せられる)
- 検証: デデンネexデッキ **どうぐ多投38.4% vs どうぐ抜き25.5% (+12.9pt)**

**導かれた公理: 「デッキ内の別カードでアタッカーの打点が決まる」タイプのコアは、
そのカードをセットで積んで初めて成立する。カード単体のスタッツではなく、
テキストが要求する周辺カードまで含めて構築を最適化する必要がある** (エネ加速の
「相方指名」、どうぐシナジーの「どうぐ多投」はいずれもこの原理の系)。

### 第8次実験: 一貫性理論の検証 (ドロー/サーチの実装)

これまでシミュレータはモンスターボール(たねサーチ)と博士の研究(2ドロー)しか
持たず、「一貫性」(毎試合同じ動きができるか) を正面から検証できていなかった。
ドロー/サーチ系を実装した:

- **アオイ** (山札から2進化をサーチ) / **セレナ** (メガexをサーチ) / **ルチア** (小型たね2枚) /
  **ナンジャモ** (手詰まり時に手札を引き直し) / **ポケモン通信** (進化先を掘る)
- 副産物のバグ修正: 「サポートは1ターン1枚」の判定を手札枚数差で見ていたため、
  手札が増えるドロー系サポート(博士の研究含む)で枠を消費しない不具合を、
  カードの消失判定に変更して修正

2進化デッキにアオイ、メガデッキにセレナを条件付き定番として追加。検証:

| | 勝率 | 初攻撃ターン |
|---|---|---|
| ドロー/サーチ あり | **56.6%** | 2.92 |
| なし (キズぐすり等で代替) | 51.2% | 2.84 |

**+5.4pt**。注目すべきは初攻撃ターンが**わずかに遅い**こと。一貫性の価値は
「早く殴る」ことではなく「デッキの主役を確実に組み上げる」ことだと分かる。
アオイで2進化を掘れると、立ち上がりは1テンポ遅くても大型アタッカーを
毎試合きちんと着地させられる。**一貫性 ≠ 速度、一貫性 = 再現性。**

### 第9次実験: デッキテーマの一貫性 (そぐわないカードの排除)

構築を目視すると、超デッキに草のワタッコexライン、悪デッキにも同じ草ラインが
入る現象があった。原因は「無色コストのワザは何色でも撃てる」ため、別色タイプの
ポケモンが色フィルタを素通りしていたこと。テーマ的に噛み合わず(弱点も進化補助も
バラバラ)、デッキの軸がぼやける。

そこで相方に**タイプ一貫性の制約**を追加: 相方は「デッキ色と一致するタイプ」か
「無色タイプ(本当に色を選ばない)」に限る。色付きの別色ライン(超デッキの草ex等)は
相方候補から除外する。

結果、構築が実戦的に一貫化した:
- ミュウツーex(超): 草のワタッコex → **超のラルトス〜メガサーナイトex**
- ダークライex(悪) / ミライドンex(雷) / ギャラドスex(水) いずれも単色ラインで統一

しかも**勝率も上昇** (対実Tier 52.2%→**53.2%**)。テーマ外の別色ポケモンは
見た目だけでなく実際に弱かった(弱点が割れる・色事故・シナジー皆無)。
**導かれた公理: デッキの「色の一貫性」は美観ではなく強さ。無色による安易な
スプラッシュより、弱点と支援カードが噛み合う単色の軸が勝率に直結する。**

### 第10次実験: 進化ラインの本数制限 (実戦の定石)

実戦の定石「2進化ラインは1種類まで / 1進化ラインは2種類まで」を構築エンジンに
実装 (**コア自身のラインも数える** ように修正)。従来は相方の2進化しか数えず、
リザードンex(2進化)デッキにメガバシャーモex(2進化)を足して**2進化2本**の
事故りやすいデッキを組んでいた。

固定ガントレット・各1500戦での検証 (cap有=定石 / cap無=無制限):

| コア | cap有(定石) | cap無 |
|---|---|---|
| リザードンex | 32.1% | **54.8%** |
| メガサーナイトex | 53.4% | 53.4% |
| ディアルガex | 52.1% | 52.1% |
| セレビィex | 61.6% | 61.1% |
| その他4コア平均 | ほぼ同値 | ほぼ同値 |

**リザードンex以外は完全に中立** (cap有50.2% / cap無50.1%)。制限は基本的に
勝率を損なわず、デッキを定石通りに一貫化させる。

**重要な例外 — テーマに沿う2進化2本**: リザードンex+メガバシャーモexは*どちらも炎*で、
20枚デッキでは「大型炎アタッカーを2系統持つ冗長性」がむしろ強い (54.8% vs 32.1%)。
一般則「2進化は1種類」は60枚TCG由来。20枚・山札を大量に掘る環境では、
**デッキテーマに沿う(=デッキ色と一致する)** 2進化なら2本目も分散ではなく
冗長性として働く。

**採用した最終ルール**: 進化ラインは「種別ごとの上限」かつ「総本数の上限」で管理する:
- 2進化ライン: **2本まで** (2本目は onTheme 制約によりデッキ色と一致=テーマ内に限られる)
- 1進化ライン: 2本まで
- 進化ライン総数: **3本まで** (4本以上は狙ったカードが手札に来ず事故る)
- たね単体: 無制限

これによりリザードンexは炎2進化2系統を取り戻し (勝率回復)、他デッキは
テーマ外の別色2進化を弾いたまま総数3本以内に収まる。**「テーマに沿うなら例外あり、
ただし総数で歯止め」** が完全データ下での結論。`maxStage2Lines/maxEvoLines` で調整可能。

### 第11次実験: 無色汎用カードへの依存を断つ (テーマ徹底)

第9次のタイプ一貫性フィルタは「別色ライン」を弾いたが、抜け道が残っていた:
**無色タイプの汎用アタッカー**(ケンタロスex等)は「無色=どのデッキにも合う」扱いで
素通りし、8デッキ中6デッキに同じケンタロスexが入る=全デッキが同じ顔になっていた。
「無色1エネで効率よく殴れる万能カード」をコスト効率最優先のスコアが拾い続ける癖。

対策: 無色タイプの相方に減点 `colorlessP` を導入し、デッキ色に属する相方を優先。
無色スプラッシュは同色候補が乏しいときの受け皿に留める。探索結果:

| colorlessP | 対Tier | ケンタロスex採用 |
|---|---|---|
| 0 | 51.3% | 6/10デッキ |
| 15〜25 | 50.2% | 2/10 |
| **40** | **51.3%** | **0/10** |

**colorlessP=40 を採用**。勝率は無ペナルティと同値のまま、汎用カードが消えて
各デッキが自色のカードで固まった (ダークライ→アクジキングex、ミライドン→ジバコイル
ライン等、テーマに沿うexが代わりに入る)。**汎用の万能カードは"置き換え可能"** ——
同色の相方で同等の強さが出るので、テーマ性を捨ててまで無色に頼る必要はなかった。
(無色をコアにしたデッキは色付きの殻を選ぶので従来どおり成立する。)

**導かれた公理: 「どのデッキにも入る万能カード」はスコアの罠。放置すると全デッキが
均質化する。テーマ(色)に属するカードを明示的に優先して初めて、デッキは"らしさ"を保つ。**

## 6. 理論の総点検 (完全データでの再検証)

トレーナー効果・特性・どうぐ・スタジアム・エネ加速・タイプ相性を全てデータ化・
実装し終えた時点で、看板となる重みを実Tier1相手に再検証した。

**確定数しきい値は「現行のまま」が最良**だった。完全データでの実Tier1のHP分布は
140〜170 (大型ex) と190〜210 (メガ) に偏るが、この分布に**寄せて**しきい値を
再導出すると勝率はむしろ落ちた:

| しきい値 | 対実Tier (各800戦) |
|---|---|
| **現行 [50,80,120,150,190]** | **51.8%** |
| 新メタ寄せ [60,140,160,190] | 43.0% |
| 新メタ寄せ2 [60,140,170,200] | 44.1% |
| 細かめ [60,90,140,160,190,210] | 44.5% |

**導かれた公理: 確定数しきい値は「現メタ上位デッキのHP」ではなく「カードプール全体で
頻出するHP帯」に張るべき。** 上位4デッキのHPに過剰適合すると、中型 (60〜120) を
一撃で取れるアタッカー ＝ 実は良デッキの背骨 を過小評価してしまい、汎化性能が落ちる。
確定数理論は「今のメタを狙い撃つ」のではなく「どんな相手でも1発少なく倒せる」構築を
選ぶための道具である、という位置づけが再確認された。

**その他の看板重みも全て維持**: コスト効率最優先 (costP=35) / 単色優先 /
ex肯定 (exB=30) / メガペナルティ10 / トレーナー枠6 (どうぐ・エネ加速シナジー時は
条件付きで拡張) / タイプ相性 (typeDefP=40) / 2色色濃度減点 (dualTypedP=10)。
完全データを入れても採用値は動かず、各項の妥当性が独立に裏づけられた。
