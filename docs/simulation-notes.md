# デッキ強さ研究ノート（簡易対戦シミュレーション）

「おまかせ構築」のスコアリングを、勘ではなくシミュレーション結果で決めるための研究記録。

## 手法

`sim.js` の簡易対戦シミュレータでデッキ同士をモンテカルロ対戦させ、勝率で比較した。

**モデル化しているルール**: 3ポイント先取 / exきぜつ=2pt / 初手5枚(たね保証) / ベンチ3 /
先攻初ターンはエネルギーなし / エネルギーゾーンから毎ターン1個(デッキのタイプからランダム) /
出したターン・初ターンは進化不可 / ふしぎなアメ / 弱点+20 / タイプ指定コスト /
主要トレーナーズ(モンスターボール・博士の研究・キズぐすり・カスミ・ふしぎなアメ)の簡易効果

**v2で追加**: ワザの付帯効果を効果テキストから解析して実処理
(コイン依存ダメージ4種 / ベンチ狙撃・全体 / 自傷 / 回復 / 自己エネ加速・トラッシュ /
どく・ねむり・マヒ / 次ターン軽減 / ベンチ数・相手エネ数比例ダメージ)。
頻出603ワザ分をカバー(効果持ちワザの46%、登場頻度ベースではそれ以上)。

**v3以降で追加**: 特性の解析(軽減/HP+/エネ加速/毎ターン回復・狙撃など) /
妨害・補助トレーナー(ナツメ・サカキ・レッドカード・おおきなマント・スピーダー/リーフ) /
にげるコスト(コスト分のエネルギーをトラッシュ。払えなければ居座り) /
エネルギートラッシュの追跡 / エネ加速トレーナー6種
(カスミ・タケシ・デンジ・カキ・メリッサ・エレキジェネレーター・ほのおのパッチ —
トレーナー効果文はTCGdexリポジトリ由来。B2b以降の弾は上流未収録のため未対応) /
**サポートは1ターン1枚** の公式ルール /
どうぐ7種 (おおきなマント・ゴツゴツメット・どくバリ・リーフマント・たべのこし・
オボンのみ・ラムのみ — 1体1枚ルール込み) /
スタジアム4種 (トレーニングエリア・はじまりの平原・ふしぎな広場・テーブルシティ —
場に1枚で上書き、効果はお互いに及ぶ。B2b以降の6種は効果文が上流未収録のため未実装)。

**v4で追加**: ドロー/サーチ系サポート (アオイ=2進化サーチ / セレナ=メガexサーチ /
ルチア=小型たね2枚 / ナンジャモ=手札引き直し / ポケモン通信=進化先を掘る) /
どうぐシナジー打点 (デデ・サーキット等「どうぐの数×N」) /
「サポートは1ターン1枚」判定の修正 (手札増加系でも正しく枠を消費)。

**残る簡略化(限界)**: 山札操作系の一部、上記以外のレア効果。
→ 特性シナジー型のコンボデッキは依然としてやや過小評価される。

**データの収録状況 (2026-07 再収集後)**: ワザ/特性なしのポケモン 226枚→**0枚**
(B3b/P-Bのワザ・HP・弱点・にげるは pokeclaude=Limitlessスクレイプ由来、
進化段階・進化元は既収録カードの同種族から引き継ぎ)。
**第5次データ収集 (カード画像からの直接転記)**: どの公開DBにも無かった残りの穴を、
Limitlessのカード画像 (GitHubミラー経由) を直接読んで埋めた:
- **新規トレーナー26種の効果文** (B2a〜B3b。ミラクルデイズ含む) → 全訳
- **ポケモンの特性7種** (ミロカロスex「アクアチャージ」、カビゴン「マッシブボディ」、
  ヒスイヌメルゴン「がんじょうシェルター」等。ex・別アート含め20枚に付与)
- **コスト誤りの修正**: デデンネex「デデ・サーキット」は無色2の推定→実際は**雷2**。
  エネルギー色はデッキ構築の色理論に直結するため画像で確定 (種族名で3枚に反映)
- 効果テキストのノーブレークスペースを正規化し、翻訳辞書の完全一致を担保

結果: **未訳のトレーナー効果・特性・ワザ効果は全て0件**。上流DBが追いつけば
これらのフォールバック辞書は自然に不要になる。残る限界は B3bの
「ポケモンのどうぐ枚数」シナジー (デデンネex/エモンガ等) を構築エンジンが未評価な点。

## 実験と結果 (2026-07 / 2480枚データ)

### H1: 2進化デッキに「ふしぎなアメ」は必須か
リザードンexデッキで、アメあり 48.4% vs アメなし(キズぐすり代替) 51.8%(3デッキ相手×800戦)。
**このシミュレータの精度では有意差なし**。アメの実装が簡易なため、実戦での評価は保留。

### H2: エネルギーは単色か2色か → **単色が明確に有利**
同じコア(ピカチュウex)で単色 23.2% vs 2色 15.2%。エネルギーゾーンが2色だと
欲しい色が来ない事故が構造的に発生する。
→ 提案エンジンは「コアが1色で賄えるなら単色」に変更済み。
→ **v2(効果込み)で再検証: 単色 52.5% vs 2色 14.3% と差はさらに拡大**。

### H3: 何が勝率を決めるか → **ワザのコスト効率が支配的**
スコア重み {HP, exボーナス, 進化ペナルティ, コストペナルティ} を2段階グリッドサーチ
(計108設定 × 6コア × 4相手 × 300戦)。
- コストペナルティ35の設定が上位を独占(~80%)、コスト無視(0)は全て最下位圏(~46%)
- HP・exボーナスは副次的、進化ペナルティはコスト考慮下では小さい
→ **「でかい打点」より「軽くて速い打点」**。採用値: hpW=0.3, exB=30, stageP=15, costP=35

### アーキタイプ総当たり (v2効果込み・9アーキタイプ36対戦・各600戦)
ダークライex(悪) 75.9% > ルカリオ(闘) 61.6% > ギャラドスex(水) 60.9% >
セレビィex(草) 56.9% > ディアルガex(鋼) 52.1% > ミュウツーex(超) 45.6% >
ピカチュウex(雷) 43.0% > リザードンex(炎) 33.7% > カビゴンex(無色) 20.3%

見どころ:
- 弱点+20が本格的に効く (リザードンexは水相手に勝率1割台)
- カスミの加速・どく等の付帯効果込みでも「軽いワザ+高効率」原則は不変
- 重み再探索でも costP=35 帯が上位独占 (stagePのみ10へ微調整)

### v3: 特性ほか優先度上位の効果を実装 (2026-07)

未対応リストの優先度1〜5を実装した:
- **特性**: 常時ダメージ軽減 / HP増加 / 味方打点強化 (ルカリオ等) / 毎ターンエネ加速
  (サーナイト等) / エネ設置時ダメージ (ダークライex) / 毎ターン回復・固定ダメージ
- **状態異常の追加**: やけど (20ダメ+コイン回復)、こんらん (ウラでワザ失敗)
- **ワザロック** (「次の番ワザが使えない」)、**相手エネルギー破壊**、**味方ベンチへのエネ加速**
- **条件付き追加ダメージ** (相手がex/たね/ダメージあり/特殊状態、自分がダメージあり/なし)
- **全体攻撃**、**連続攻撃** (メガガルーラex)

効果テキストの解析カバー率: 46% → **57%** (登場頻度ベースではさらに高い)。

v3での再計測 (9アーキタイプ総当たり):
ルカリオ(闘) 75.6% > ディアルガex(鋼) 60.8% > ギャラドスex(水) 59.4% >
セレビィex(草) 56.8% > ダークライex(悪) 54.2% > ミュウツーex(超) 43.9% >
ピカチュウex(雷) 42.2% > リザードンex(炎) 30.2% > カビゴンex(無色) 27.0%
→ 打点強化特性が反映されたルカリオが1位に浮上。

### 特性ボーナスの重み実験 → **一律加点は逆効果**

「特性を持っているカードに+Nする」重み(abB)を探索したところ、
abB=0: 62.4% > 10: 60.1% > 20: 51.8% > 35: 41.2% > 50: 39.1% と単調悪化。
弱いアタッカーが状況依存の特性で紛れ込むデメリットの方が大きい。
良い特性(打点強化・加速)は結局ワザの強さ経由で勝率に現れるため、既定値は abB=0 とした。

### メガ進化ポケモン (v2.1: きぜつ=3ポイントを実装)

メガ6種+強アーキタイプ3種の総当たり(36対戦×600戦)と、同一進化ラインのメガ有無比較:

- 総合: **メガギャラドスex 67.1% ≒ 通常ギャラドスex 67.0%** (直接対決はメガ側53.3%、
  強デッキ群相手ではメガ57.6% vs 通常58.2%)
- → **メガ化は「高スペックと引き換えに、きぜつ1回で3ポイント献上」のほぼ等価交換**。
  デッキパワーの底上げにはならず、リスク選好の問題
- メガ内の序列: ギャラドス(1進化・軽ワザ) > サーナイト(エネ加速) > フシギバナ >
  リザードンY(250打点だが4エネ+自傷50で回収されやすい) ≫ デンリュウ・ガルーラ
- 2進化メガ+重コストは「立ち上がり前に轢かれ、育てても3ポイント払う」二重苦
- ※メガガルーラexの「2回連続攻撃」等、未解析の効果は過小評価に注意

## シミュレータ監査 (第17次)

「構築の幅を広げようとすると必ず勝率が下がる」という不自然な結果が続いたため、
測定器そのものを疑って監査した。

### 見つかった構造的な偏り: 使えなかったトレーナーを捨てていた

トレーナー処理の最後が `else { me.hand.splice(i, 1); }` になっており、
**その番に使えなかったトレーナーが手札から消えていた**。元々は「効果未実装の札が
手札を圧迫しないように」という意図だったが、汎用処理を入れた後もこの分岐が残ったため:

- 無傷のときに引いたキズぐすり → 即消滅
- 相手のベンチが空のときのアカギ → 即消滅
- 確定数が動かない場面のサカキ → 即消滅

つまり**状況を選ぶ札が原理的に一度も働かない**測定器になっていた。
これが「いつでも使える札 (ボール/博士/エネ加速) だけが強い」「グッズや
1枚差しを増やすと必ず勝率が落ちる」という偏りの正体だった。
実プレイ通り「使えない札は手札に残る」に修正した。

### 修正の影響

| 実験 | 修正前 | 修正後 |
|---|---|---|
| 旧エンジン vs 新エンジン | +3.5pt | **+4.2pt** |
| トレーナー枠12 (ガイド通りの配分) | -0.7pt | +0.2pt |
