# デッキ強さ研究ノート（簡易対戦シミュレーション）

「おまかせ構築」のスコアリングを、勘ではなくシミュレーション結果で決めるための研究記録。

## 手法

`sim.js` の簡易対戦シミュレータでデッキ同士をモンテカルロ対戦させ、勝率で比較した。

**モデル化しているルール**: 3ポイント先取 / exきぜつ=2pt / 初手5枚(たね保証) / ベンチ3 /
先攻初ターンはエネルギーなし / エネルギーゾーンから毎ターン1個(デッキのタイプからランダム) /
出したターン・初ターンは進化不可 / ふしぎなアメ / 弱点+20 / タイプ指定コスト /
主要トレーナーズ(モンスターボール・博士の研究・キズぐすり・カスミ・ふしぎなアメ)の簡易効果

**v2で追加**: ワザの付帯効果を効果テキストから解析して実処理
(コイン依存ダメージ4種 / ベンチ狙撃・全体 / 自傷 / 回復 / 自己エネ加速・トラッシュ /
どく・ねむり・マヒ / 次ターン軽減 / ベンチ数・相手エネ数比例ダメージ)。
頻出603ワザ分をカバー(効果持ちワザの46%、登場頻度ベースではそれ以上)。

**残る簡略化(限界)**: 特性、上記以外のレア効果、にげるコスト。
→ 特性シナジー型のコンボデッキは依然として過小評価される。

## 実験と結果 (2026-07 / 2480枚データ)

### H1: 2進化デッキに「ふしぎなアメ」は必須か
リザードンexデッキで、アメあり 48.4% vs アメなし(キズぐすり代替) 51.8%(3デッキ相手×800戦)。
**このシミュレータの精度では有意差なし**。アメの実装が簡易なため、実戦での評価は保留。

### H2: エネルギーは単色か2色か → **単色が明確に有利**
同じコア(ピカチュウex)で単色 23.2% vs 2色 15.2%。エネルギーゾーンが2色だと
欲しい色が来ない事故が構造的に発生する。
→ 提案エンジンは「コアが1色で賄えるなら単色」に変更済み。
→ **v2(効果込み)で再検証: 単色 52.5% vs 2色 14.3% と差はさらに拡大**。

### H3: 何が勝率を決めるか → **ワザのコスト効率が支配的**
スコア重み {HP, exボーナス, 進化ペナルティ, コストペナルティ} を2段階グリッドサーチ
(計108設定 × 6コア × 4相手 × 300戦)。
- コストペナルティ35の設定が上位を独占(~80%)、コスト無視(0)は全て最下位圏(~46%)
- HP・exボーナスは副次的、進化ペナルティはコスト考慮下では小さい
→ **「でかい打点」より「軽くて速い打点」**。採用値: hpW=0.3, exB=30, stageP=15, costP=35

### アーキタイプ総当たり (v2効果込み・9アーキタイプ36対戦・各600戦)
ダークライex(悪) 75.9% > ルカリオ(闘) 61.6% > ギャラドスex(水) 60.9% >
セレビィex(草) 56.9% > ディアルガex(鋼) 52.1% > ミュウツーex(超) 45.6% >
ピカチュウex(雷) 43.0% > リザードンex(炎) 33.7% > カビゴンex(無色) 20.3%

見どころ:
- 弱点+20が本格的に効く (リザードンexは水相手に勝率1割台)
- カスミの加速・どく等の付帯効果込みでも「軽いワザ+高効率」原則は不変
- 重み再探索でも costP=35 帯が上位独占 (stagePのみ10へ微調整)

### メガ進化ポケモン (v2.1: きぜつ=3ポイントを実装)

メガ6種+強アーキタイプ3種の総当たり(36対戦×600戦)と、同一進化ラインのメガ有無比較:

- 総合: **メガギャラドスex 67.1% ≒ 通常ギャラドスex 67.0%** (直接対決はメガ側53.3%、
  強デッキ群相手ではメガ57.6% vs 通常58.2%)
- → **メガ化は「高スペックと引き換えに、きぜつ1回で3ポイント献上」のほぼ等価交換**。
  デッキパワーの底上げにはならず、リスク選好の問題
- メガ内の序列: ギャラドス(1進化・軽ワザ) > サーナイト(エネ加速) > フシギバナ >
  リザードンY(250打点だが4エネ+自傷50で回収されやすい) ≫ デンリュウ・ガルーラ
- 2進化メガ+重コストは「立ち上がり前に轢かれ、育てても3ポイント払う」二重苦
- ※メガガルーラexの「2回連続攻撃」等、未解析の効果は過小評価に注意
