# 戦国合戦絵巻

戦国時代の代表的な四つの合戦を、**勢力図と部隊の動き**で追えるビジュアルアプリ。
`index.html` 一枚だけの完全自己完結型で、外部通信もビルドも不要。

## 収録している合戦

| 年 | 合戦 | 対戦 | 見どころ |
|---|---|---|---|
| 1560 | 桶狭間の戦い | 織田信長 vs 今川義元 | 寡兵二千が二万五千の本陣を突く |
| 1561 | 第四次 川中島の戦い | 武田信玄 vs 上杉謙信 | 啄木鳥の戦法と車懸りの陣 |
| 1575 | 長篠の戦い | 織田・徳川 vs 武田勝頼 | 馬防柵と鉄砲が騎馬軍団を砕く |
| 1600 | 関ヶ原の戦い | 西軍 vs 東軍 | 小早川秀秋の裏切りで六時間の決着 |

## iPhone での開き方（ローカル）

いずれも **オフラインで動作** します。

**A. AirDrop / メール / iCloud Drive で送る**
1. `index.html` を iPhone に送る
2. ファイルアプリから開く（Safari で表示されます）

**B. Mac などから同じ Wi-Fi で配信する**
```sh
cd sengoku
python3 -m http.server 8000
```
iPhone の Safari で `http://<PCのIPアドレス>:8000/` を開く。

**ホーム画面に追加**すると、Safari の UI が消えてアプリのように全画面で使えます
（共有ボタン → 「ホーム画面に追加」）。

## 使い方

- 一覧から合戦を選ぶ
- 下部の **‹ ›** ボタンか丸いドットで**局面を送る**（各合戦5局面）。部隊マーカーがアニメーションで移動します
- 地図は**1本指でドラッグして移動**、**2本指でピンチして拡大縮小**。右下の `⤢` で元に戻ります
- 円の**大きさが兵力**、**色が陣営**。✕印は壊滅・討死した部隊、破線の円は寝返った部隊（小早川秀秋）
- 上部の帯は各局面の**戦況（優勢度）**を表します

キーボードでは ← → で局面送り、Esc で一覧に戻ります。

## 実装メモ

- 依存ライブラリなし。HTML / CSS / SVG / 素の JavaScript のみ、1ファイル約 900 行
- 合戦データは `BATTLES` 配列にまとまっています。地形・地名・城砦・部隊・局面をすべてデータで記述しているので、合戦を追加する場合はここに1件足すだけです
  - `pos: { 局面番号: [x, y] }` — 指定のない局面は直前の座標を引き継ぐ
  - `born` / `dead` / `exit` / `flip` — 登場・討死・退場・寝返りの局面
  - `adv` — その局面の優勢度（0 = 左の軍が完全優勢、1 = 右の軍が完全優勢）
- 地図は iPhone の画面比に合わせた縦長 viewBox。長篠・関ヶ原は東西方向が主軸のため図を回転させてあり、**方位記号**（左下、関ヶ原も左下）で真北を示しています

## 注意

兵力・時刻は主要な通説にもとづく概数です。地図は位置関係を伝えるための模式図であり、
実際の縮尺・地形とは異なります。
