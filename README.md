# 🎴 ポケポケ デッキビルダー

Pokémon TCG Pocket（ポケポケ）のデッキを、カードのサムネイル画像を見ながら組めるWebアプリです。
ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）なので、そのままブラウザで動きます。

## 使い方

### すぐ試す（ローカル）

```bash
# リポジトリのフォルダで適当なHTTPサーバーを起動
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

`index.html` をダブルクリックして直接開いても動作します。

### GitHub Pages で公開する

リポジトリの **Settings → Pages → Branch** でこのブランチ（または main）の `/ (root)` を選ぶだけで、
`https://<ユーザー名>.github.io/1st/` で公開できます。

## 機能

- 🖼 **サムネイルでカード選択** — 全拡張パックのカードをグリッド表示。クリックで拡大＆デッキに追加
- 🔍 **検索・絞り込み** — カード名検索（ひらがな/カタカナ対応）、拡張パック / カテゴリ / タイプ / 進化段階 / レアリティのフィルタ
- 🃏 **ポケポケのルールでデッキ構築**
  - デッキは **20枚** ちょうど
  - **同名カードは2枚まで**（イラスト違いも合算）
  - エネルギータイプの選択（最大3タイプ）
  - たねポケモン未投入の警告
- 💾 **デッキの保存** — ブラウザ（localStorage）に複数デッキを保存・読み込み・削除
- 📤 **テキスト出力 / 読み込み** — `2 ピカチュウex (A1-094)` 形式でコピー＆共有、貼り付けて復元
- 📱 **スマホ対応** — モバイルではデッキパネルがスライド表示

## カードデータについて

カード情報とサムネイル画像は [TCGdex API](https://tcgdex.dev/) の Pokémon TCG Pocket シリーズ（`tcgp`）から
**ブラウザ上で直接** 取得しています（APIキー不要・無料）。

- 日本語データを優先し、取得できない場合は英語にフォールバック
- 取得結果は24時間ブラウザにキャッシュ（🔄ボタンで強制再取得）
- タイプ・進化段階などの詳細データは初回アクセス時にバックグラウンドで少しずつ取得し、
  ブラウザに永続キャッシュします（取得完了までは詳細系フィルタの結果が段階的に増えます）
- 新パックがAPIに追加されれば自動で反映されます

> **攻略サイト（GameWith等）からの取得について**: ブラウザのCORS制限と各サイトの利用規約の関係で
> 直接のスクレイピングは行いません。攻略サイトのカード一覧に載っている情報（タイプ・HP・進化・レアリティ等）は
> 同じものがTCGdexの中立なカードデータとして取得できるため、そちらを使っています。
> デッキ構築を縛る要素（メタ情報など）はアプリには含まれていません。

## 「今の環境をXから取得」について

X（旧Twitter）からの自動取得は、**APIが有料**（無料枠は実質読み取り不可）で、規約上スクレイピングも
禁止されているため、現実的ではありません。

代わりに、ヘッダーの「📊 環境デッキを見る」から [Limitless TCG Pocket](https://pocket.limitlesstcg.com/decks?lang=ja)
（大会結果ベースのメタデッキ集計サイト）に飛べるようにしています。気になるデッキを見つけたら、
このアプリでカードを検索して再現 → 保存、という使い方を想定しています。
